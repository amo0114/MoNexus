# 后端架构整改与 FakaBridge 可选安装

## Why

修复 2026-11-24 后端架构评审的 BE-01 至 BE-08，并让通用 MoNexus 部署可以完全省去 FakaBridge/Xboard。Owner 于 2026-11-24 在本次会话批准实施并要求一个 PR。

## What Changes

- 修复 FakaBridge 的重试时区及钱包开户边界，补齐依赖环和 API 契约门禁。
- 收拢平台履约、支付与充值、下单交付、集成配置的边界。
- 保留历史履约的渠道、操作号和配置版本，支持单独交付、运行期间装载及启停。
- 触及订单、余额、并发锁、幂等、授权、迁移兼容与任务认领。保留原事务与远端执行边界。

本次由可信部署制品提供插件。生产部署和历史数据处置由既有交付流程负责。
