# 可选 FakaBridge 履约

## ADDED Requirements

### Requirement: 核心商城可以独立部署

核心商城 MUST 能在没有 FakaBridge 制品、配置和专属迁移时完成普通交易。

#### Scenario: 纯商城安装

- **WHEN** 使用不含插件的制品初始化独立数据库并启动
- **THEN** 普通商品可发布、下单、交付和退款，插件的路由、页面和后台任务均不启用

### Requirement: 暂停和移除遵守历史订单边界

系统 MUST 在运行期间支持装载已准备好的插件、暂停接单、恢复和安全注销。

#### Scenario: 暂停存在已受理任务的供应商

- **WHEN** 运营在有已受理订单时暂停 FakaBridge
- **THEN** 暂停提交后新业务无法扣款建任务，历史任务按原操作号、端点和版本继续履约、撤销和对账

#### Scenario: 待履约或有效服务阻止移除

- **WHEN** 仍有不确定的外部结果、活动租约、待撤销或有效的订阅服务
- **THEN** 系统拒绝移除，并保留现有历史执行能力

#### Scenario: 插件缺失时处理历史订单

- **WHEN** 订单记录的外部履约方不可用
- **THEN** 历史订单及交付仍可读取，无法确认的取消或退款不自动执行
