# 三国头像 V2.3 发布说明

V2.3 定稿采用 V2.2 的24人名单，赵云、郭嘉、典韦、司马懿、庞统替换为V2.3动作稿；魏、蜀、吴各8人。制作来源、尺寸与哈希见[素材来源清单](../assets/three-kingdoms-v2.3.json)。

## 产品行为

个人资料「选择头像」按三阵营展示，点选先预览，点击「使用此头像」才写入。失败保留原头像与选择，允许重试；保存期间禁止重复提交。用户仍可上传自定义图片或清除头像，已有用户不自动换头像。

头像同步显示在个人资料、桌面顶栏与移动导航菜单。排行榜和评价的现有API尚未提供头像字段，此发布不改变这两处接口或承诺已展示头像。

## 数据与资产契约

- 复用User.avatarUrl，不增加数据库字段或迁移。
- PATCH /api/auth/me允许已有平台上传URL、null，以及后端清单中24个精确预设路径；不放开整个/assets/目录。
- 持久化路径为`/assets/avatars/three-kingdoms/v2.3/<人物ID>.webp`，443px。96px与48px仅用于响应式加载，不另存用户字段。
- 72个无损WebP合计5,217,024字节；利用现有/assets/的一年immutable缓存。页面按实际显示尺寸通过srcset加载，不一次请求所有443px头像。
- 正式资源提交到public/assets/avatars/，生成原图、弃稿、预览与ZIP留在设计目录。生产构建不依赖Python或设计源文件。
- 前端清单、后端精确白名单与所有图片在同一发布中提交；前端合同测试检查名单一致、角色替换与每张图的SHA-256。

## 验证

本地使用独立PostgreSQL测试容器：头像/上传后端27项测试，前端选择、失败重试、取消、上传/清除、防重复保存、图片失败回退与资源契约7项测试通过。前后端生产构建通过。

一条真实浏览器E2E覆盖选择赵云、服务端保存、刷新仍保留、桌面/移动导航显示及清除。375px和1440px窗口检查弹窗布局、图像加载和横向溢出。

## 发布与回退

按[分支规范](../branching-and-ci.md)从功能PR进入develop，再通过release PR进入master；遵循[Compose生产部署](compose-production-deploy.md)的同SHA CI、双架构镜像与production人工审批门槛。此功能不修改生产环境配置、不触发用户数据批量更新。

以后新增头像版本应使用新版本路径，并继续保留旧路径及其白名单。禁止覆盖v2.3已有资源，否则immutable缓存和已保存用户URL会出现版本不一致。

此版本未引入数据库迁移，但回退到首次上线前的旧web镜像会缺少这些静态文件。优先前向修复；如必须回退，应评估已选择预设用户的显示影响并保留相同静态路径，不能以批量清空用户avatarUrl代替回退。当前共享头像组件在图片失败时显示昵称首字母。

## 重新导出

在含有原始设计目录的工作区运行`python3 scripts/export-three-kingdoms-avatars.py`（需要Pillow）；该脚本用于重建此定稿，不用于覆盖未来的美术更新。输出前端清单、后端白名单和来源记录。历史设计材料未纳入生产镜像。
