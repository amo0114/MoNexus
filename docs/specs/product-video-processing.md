# 商品视频自动处理与独立审核（首版）

本补充覆盖原商品视频方案的同步硬格式校验。目标是商家直接上传手机 MP4/MOV，平台生成兼容播放的成品；技术处理成功不代表内容已获批准。

## 上传与处理

- 原片最多 90 MiB、60 秒，接收 MP4/MOV 中的 H.264/HEVC，最多 4K、120fps。限制以实际探测和解码为准，文件名/MIME 仅作选择提示。成品为 H.264 SDR、最长边 1920 / 最短边 1080、30fps、AAC-LC 双声道（有声才保留音轨），最多 40 MiB。HDR 使用 tone mapping，不能仅删除标记。绝不静默裁掉尾部或音轨。
- 上传流式落到私有临时文件，再写私有原片对象；返回 202 和资产 ID。数据库 queued/processing 是持久任务。主进程内一个工作器，FFmpeg 独立有界子进程，复用 cron 租约；资产领取令牌和截止时间防止崩溃重入覆盖成品。每次输出使用独立 UUID generation，不覆盖已有成品。
- 重启后自动领取 queued / 租约过期任务。临时存储错误最多尝试三次；无效素材直接失败。停止服务中断子进程并保留任务重试。原片不可签名播放，处理完成或终止后清理；GC 兜底。
- 上传过程中锁定表单；上传完成后可离开页面，后台继续。编辑器提供恢复未保存资产的入口。旧视频一直保留到新素材成功并由商家选择、保存。首版不把未完成资产关联商品，避免失败替换损失旧视频。

## 内容审核

- 独立 pending / approved / rejected，所有普通浏览者（包括已登录会员）只能看 approved 成品；商家所有者、管理员可预览待审视频。未审核元数据不投影到普通商品详情；签名接口再次查当前审核状态。
- 管理员在商品管理里查看已关联视频的待审队列，包含 members_only。审批绑定不可变资产 ID、当前关联商品 ID 与 moderationVersion；确认完整观看、含音轨时听完音频；拒绝/撤销填写原因。记录审核人、时间、原因及 AdminLog。勾选只记录审核声明，不声称机器证明完整观看。
- 游客公开审批要求当前关联视频已经独立通过审核。视频审核不会自行批准商品公开；撤销视频批准立即停止签发普通播放地址，已签发 URL 的存活期与既有媒体链缓存风险仍按原方案处理。
- 迁移现有视频统一 pending，普通浏览者的视频暂时隐藏，管理员补审后恢复。商品正文的可见性不受视频审核变更影响；技术处理/视频审核/游客公开是三个独立门禁。

## 运维与验收

- Nginx 视频路径上限改为 95m（原片 90 MiB 加 multipart 开销），外层代理需同样调整。原有 upload/playback 开关继续有效。暂不引入直传、HLS、多档、GPU、AI 内容审核或新消息中间件。
- 便携备份只带 ready 成品，未完成任务跨环境恢复标记 failed，商家重新上传；恢复前后成品 generation 和审核状态保持一致。GC 仅删本命名空间内、超宽限期且无当前引用/活跃任务的原片和成品。
- 后端集成覆盖真实媒体、异步恢复、租约 fencing、审核 CAS、会员/游客门禁、归属、GC/备份；组件覆盖进度和失败保留。沿用既有视频 E2E 更新上传/审核旅程。
- 独立媒体出口和签名配置的后续任务仍保留在生产验收记录中，此功能不声称修复第三方 SaaS 缓存链。
