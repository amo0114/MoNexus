# Archive

Historical and process materials that are **not required to build, run, or operate** MoNexus.

These files are kept for archaeology and decision context only. Prefer current product docs under:

| Live docs | Purpose |
| --- | --- |
| [`docs/superpowers/specs/`](../superpowers/specs/) | PRD, design specs, OpenAPI |
| [`docs/operations/`](../operations/) | Runbooks, deploy, alerts |
| [`docs/api/`](../api/) | API notes |
| [`design-system/monexus/`](../../design-system/monexus/) | Active design tokens / assets |

## Layout

| Path | Former location | Contents |
| --- | --- | --- |
| [`mvp-prototype/`](./mvp-prototype/) | `项目mvp原型/` | Early single-page MVP HTML + favicons |
| [`design/`](./design/) | `design-system/monexus/HANDOFF-*.md` | UI redesign handoff notes |
| [`plans/`](./plans/) | `docs/superpowers/plans/` | Milestone execution plans / reviews |
| [`ui/`](./ui/) | repo-root progress notes | UI redesign progress snapshots |

## Policy

- Do not add new operational procedures here — put them in `docs/operations/`.
- Do not reference archive paths from CI, Docker, or runtime config.
- Safe to delete later if the team no longer needs history (git history still retains them).
